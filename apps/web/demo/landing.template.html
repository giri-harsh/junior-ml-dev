How it works

Five steps, no hand-holding.

01 PROFILE

Look at the data

Rows, columns, types, missing values, duplicates.

02 LEAKAGE

Check for cheats

Columns that give the answer away are flagged and dropped. Skipped in this demo to fit the free CPU.

03 RACE

Train and compare

A baseline, a linear model, boosting and a forest, scored on held-out data.

04 REVIEW

Check its own work

A deterministic reviewer signs off or sends the run back.

05 EXPLAIN

Write it up

A plain-English summary, the top features and a model card.

Not in this demo

What the full system does

  • An LLM planner and a critic, with a structural guard against prompt injection.
  • Leakage detectors and FLAML AutoML (both switched off here: this server has 0.1 of a CPU).
  • Agent-written feature code in a sandbox (Docker or E2B), and gated model deployment with a single-use approval.
  • Bring-your-own CSV. The demo has no upload at all: the server accepts no files.
