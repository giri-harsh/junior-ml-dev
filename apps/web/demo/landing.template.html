junior-ml-dev GitHub repository

A junior ML engineer that shows its work and catches its own mistakes.

It profiles a tabular dataset, checks for leakage before modelling, trains and compares models against baselines, has a deterministic reviewer sign off, and writes a report. Deployment is gated by a single-use approval; this demo has deployment switched off.

    What this demo is, and is not

    • It runs the real agent harness on three small public OpenML tables bundled in the image. There are no uploads, no model deployment, and no code execution sandbox on this server.
    • The planner is the deterministic scripted one. The benchmark numbers above come from larger tasks and longer budgets than a demo run allows, so a demo run will not reproduce them.
    • Runs are rate limited, queued one at a time and deleted after a short while. Admin endpoints need a login.
