A junior ML engineer that shows its work and catches its own mistakes.

It profiles a tabular dataset, checks for leakage before modelling, trains and compares models against baselines, has a deterministic reviewer sign off, and writes a report. Deployment is gated by a single-use approval.

This is a static site, not a live demo. The example runs below were computed once with the project's scripted planner (no LLM) on a developer laptop (Windows 11), CPU only, and are shown as recorded. A live, interactive version needs a host that runs Python; a free Hugging Face account cannot create Docker or Gradio Spaces. The source repository is currently private, so file references below (result JSONs, code) are names only, not links.
